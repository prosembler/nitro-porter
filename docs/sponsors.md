# Sponsorship

In 2026, the [Open Social Fund](https://nlnet.nl/opensocial), a fund established by [NLnet](https://nlnet.nl/),
sponspored major development work in the 5.0 release:

* Discord was added as the first Origin, a data-retrieval step, using their API.
* Discord support was added as a Source, the first with complete key renumbering.
* NodeBB support was added as a Target, along with MongoDB output for the first time.
* Agorakit support was added as a Target.
* Discourse support was added as a Target, along with PostgreSQL output for the first time.

We thank them for their generous support and consultation. These features represent a large leap forward for the project and would have taken many years without it.

If you or your organization is interested in sponsoring this project, please contact sponsors@prosembler.com.
